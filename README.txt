ZAZO TYCOON V15 CORE — YENİDEN TASARIM

Bu sürüm görsellerden bağımsız olarak oyunun çekirdeğini yeniden kurar.

TEMEL DÜZELTMELER
- Holding kasası, şirket kasası ve kişisel para artık ayrı ve açık.
- Kredi çekilirken para nereye gidecek seçilir.
- Holding <-> şirket para transferi çalışır.
- Üstte para görünüp 'kasa yetersiz' çıkma karmaşası azaltıldı.
- Şirket satın alımları yalnızca şirket kasasını kullanır.

OYUN DÖNGÜSÜ
- Şirket kur
- Holding kasasından şirkete sermaye aktar
- Toptancıdan ürün al
- Mağaza aç
- Satış çalışanı al
- Otomatik satış başlar
- Depoyu büyüt
- Fabrika kurup daha ucuza üret
- Şirket 50 seviyeye kadar büyür
- Holding 100 seviyeye kadar büyür

SATIŞ
- Hızlı: sık, az adet
- Dengeli: normal
- Gerçekçi: seyrek, toplu, yüksek marj
- Uygulama kapalıyken geçen süre dönüşte hesaplanır.
- Görünürken sadece dakikada bir kontrol yapılır; gereksiz pil tüketimi azaltılır.

BANKA
- Kredi
- Para transferi
- Mevduat
- Hisse / kripto / altın / gümüş yatırımı

VERİ
- Eski sürümlerdeki localStorage 'zfull1' kaydı mümkün olduğunca taşınır.
